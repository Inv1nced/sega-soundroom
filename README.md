# Soundroom

Сайт: https://inv1nced.github.io/sega-soundroom/

Личная музыкальная комната: Love Blur, Daytona и promise от slayr.

Сказочный лес и эстетика SEGA: древесная надпись, северное сияние, живая лоза, улитки с мягкой деформацией тела и разные лесные обитатели. Музыка открывается в Spotify.

## Локальный запуск

Нужен Python 3. Из корня репозитория:

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://localhost:4173. Установка зависимостей и сборка не требуются.

## Файлы

- `dist/index.html` — страница.
- `dist/style.css` — оформление и CSS-анимации.
- `dist/app.js` — треки и взаимодействие.
- `dist/ecology.js` — лоза и движение обитателей.
- `dist/assets/` — оригинальный фон и SVG-элементы.
- `make-assets.py` — генератор базовых SVG-ассетов.

Кнопка «Лес оживает / Тихий лес» отключает анимации. Учитывается системная настройка уменьшения движения; анимации приостанавливаются вне экрана и в скрытой вкладке.

Шрифты загружаются из Google Fonts, обложки — из Spotify. Для публикации на статическом хостинге используется папка `dist`.

## Публикация

GitHub Pages автоматически публикует папку `dist` при изменениях в ветке `main`. Процесс можно также запустить вручную в Actions → Publish Soundroom.
